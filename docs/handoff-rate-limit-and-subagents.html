Before vs After Execution Flow
4-Point Action Plan

Action 1: Subagent Inherits Active Chat Model & BYOK Credentials

In chat-config-resolver.ts, when config.subagentChain is null or empty, automatically assign subagentLlmChain: serverChain. Subagents will immediately inherit the user's working OpenRouter / Gemini key.

Action 2: Dynamic Tier 2 Gating in Hosted Mode

Because DuckDuckGo is blocked on cloud datacenter IPs and live scraping is disabled, we gate tier2Enabled. If no paid AI search key (Tavily, Exa, Brave) is configured on hosted mode, set tier2Enabled: false and omit consult from createToolRegistry().

Action 3: Search Discipline & Convergence Prompting

Update buildSystemPrompt() to instruct the model:
• "Do not run speculative repetitive term searches when a solid candidate was already found in the price-bracket search."
• "If a candidate part lacks catalog specs (e.g. missing PSU wattage), immediately choose an alternative in-stock listing with complete specs rather than attempting research."

Action 4: Tighten Stop Step Count

Lower stopWhen: isStepCount(25) to isStepCount(14) in chat-engine.ts. A full 8-part build needs at most 1 catalog call, 5–6 searches, 1–2 validations, and 1 presentation. 14 steps provides generous safety while enforcing convergence before daily limits trip.
